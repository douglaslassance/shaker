# Shaker

Shaker is a plugin for Unreal Engine inspired from the built-in camera shake system. It provides a scene component and a generic shake blueprint class allowing to shake any actor in your level.

## Install

If your project is on Git, the recommended setup is to [submodule](https://git-scm.com/book/en/v2/Git-Tools-Submodules) this repository in your `Plugins` folder.
